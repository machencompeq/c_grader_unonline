# C 語言作業批改工具

雙擊 **`Grader.exe`**：選「學生作業資料夾」、選「題目 (參考答案 .c)」、編輯測資 → 按「開始批改」。
每位學生產生**老師版**與**學生版** HTML 比對報告，另有全班總表與 CSV。

## 批改工具資料夾

```
c-grader\
├── Grader.exe            ← 雙擊這個
├── 名單.csv              資料夾名稱 → 中文姓名、學號 (全班共用，每一題都用這份)
├── tools\
│   ├── ai_testcases.ps1  用本機 AI (claude / codex / gemini) 依參考答案產生測資
│   └── ai_roster.ps1     貼上教學平台名單，自動配對中文姓名
├── build.bat             重新編譯 (關掉 Grader 後雙擊)
├── build\grader_cli.exe  命令列版
├── src\                  原始碼      docs\DESIGN.md  程式架構   docs\ARCHITECTURE.md  架構圖
└── tests\                自動測試與邊界情況範例 (開發用)
```

## 1. 學生作業資料夾

教學平台下載、解壓縮後的資料夾，不用整理。每個子資料夾 (或散裝的 .c 檔) = 一位學生。
工具**只讀取**，不會在裡面新增或修改任何檔案。

### 中文姓名 (資料夾名稱變成英文拼音＋底線)

平台下載時把顯示名稱轉成拼音：`張敦品` → `zhang_dun_pin`、`YiZhi Hu (胡議支)` → `yizhi_hu_hu_yi_zhi`。
按「**學生名單…**」→ 選「是」→ 把平台上的名單整段複製貼上 (序號、繳交時間一起貼沒關係)：
- 英文名直接比對 (Lucas → lucas)
- 中文名交給本機 AI 依拼音配對 (只接受名單上真的有的名字與真的存在的資料夾，AI 不會亂編)
- 結果寫進 `名單.csv` 並用 Excel 開啟讓你檢查；已經填過的姓名不會被覆蓋

之後表格、報告、CSV 都顯示中文姓名。

## 2. 題目 = 一個 .c 檔

按「選擇 .c…」選老師的參考答案，例如 `D:\hw\hw1.c`。
測資、設定、報告自動放在旁邊的 `D:\hw\hw1_測資\`：

```
hw1_測資\
├── testcase\             test01.in、test01.out(可省略)、meta.txt(可見/隱藏、說明)
├── grader.cfg            這一題的評分設定 (自動儲存、自動載入)
├── reports\老師版\       index.html 全班總表 + 每人一份 (隱藏測資完整顯示)
├── reports\學生版\       每人一份，可直接發給學生 (隱藏測資只顯示結果)
└── result.csv            按「匯出 CSV」
```

## 3. 編輯測資 (總表)

按「**編輯測資…**」，所有測資在同一份文字裡，一眼看完、直接整批修改：

```
===== test01 | 可見 | 一般情況 =====
資訊管理學系 一年級 甲班 115403001 王小明
===== test02 | 隱藏 | 英文輸入 =====
CS 2 B 12345 Amy
----- 標準答案 -----              ← 可省略；省略時用參考答案的輸出
...
```

- **可見 / 隱藏**：隱藏測資照常計分；學生版報告不顯示它的輸入與答案，老師版全部看得到。
- **新增一組**、直接貼上多組都可以，儲存時依順序重新編號。
- **AI 產生測資…**：用本機的 claude / codex / gemini 讀參考答案，產生指定組數的輸入 (可寫額外要求)。
  AI 只設計輸入；標準答案一律由參考答案實際執行產生，不會因為 AI 算錯而誤判學生。
- **預覽參考答案輸出**：右邊直接看到每組測資的標準答案，確認測資合理。

## 4. 評分

- 每組測資分數相同：`滿分 / 測資數`；每題各自扣分，最低 0 分；總分 = 各題相加。
- **差異數 (CHAR)** = 把學生輸出改成標準答案最少要「新增／刪除／替換」幾個字 (中文字 = 1 CHAR)。差異 0 一律不扣分。
  完整機制 (每個步驟的例子、演算法、限制) 見 [docs/COMPARATOR.md](docs/COMPARATOR.md)。
- 時間限制預設 **60 秒 / 題**。
- **告訴學生哪裡錯**：報告每一題都有「哪裡錯了」方塊，用白話列出錯在第幾行、應該是什麼、學生印了什麼，
  並辨識常見錯誤：只差換行、全形符號、大小寫、空白數量、格式對但數字錯、沒有輸出。
  隱藏測資在學生版只給錯誤類型，不透露內容。編譯失敗會把 gcc 錯誤翻成白話，例如「第 5 行：少了分號」。

### 快速套用模板

模板**不是另一個設定**，只是「一次把下方的比對方式與評分方式填好」；真正生效的永遠是下方設定。
手動改了下方任何一項，選單會自動顯示符合的模板或「自訂設定」，兩者不會衝突。

| 模板 | 比對 | 扣分 |
|---|---|---|
| 規格預設 | Strict 逐字 | 區間：0→0、1～2→1、3～5→2、6～10→5、11～20→10、21+→20 |
| 建議 (預設) | Strict＋忽略行尾空白/結尾換行＋全形半形相同 | 同上 |
| 只看資料 | 同「建議」＋忽略含「請輸入」「請依序」的提示行 | 同上 |
| 寬鬆 | Token＋忽略大小寫/全形半形/空白行 | 每 3 CHAR 扣 1 |
| 精確 | Strict＋忽略行尾空白 | 每 1 CHAR 扣 1 |
| 全對才給分 | Strict＋忽略行尾空白 | 有差異該題 0 分 |

區間規則按「編輯評分規則…」(扣分填 `ALL` = 扣光該題)。

### 編譯失敗 (CE)：本機 AI 最小修正後繼續批改

預設開啟 (畫面上「編譯失敗與執行異常的處理」群組)。學生程式編譯失敗時：

1. 工具把**學生原始碼 + gcc 錯誤訊息**交給本機的 claude / codex / gemini 命令列工具 (自動偵測，或指定)，
   要求「只修編譯錯誤、不改邏輯與輸出、改動的字元越少越好」。
2. **修正扣分** = max(修正字元數 × 每 CHAR 扣分, **滿分的 10%**)，可再設上限。修正字元數是原始碼 → 修正後的編輯距離，中文字 = 1。
   有下限是因為「沒有先編譯成功」本身就該有代價，少一個分號也不會只扣 1 分。
3. 用修正後的程式**照常執行所有測資**，各題輸出扣分照舊。
4. **成績 = 各題得分總和 − 修正扣分，但不會低於編譯失敗保底分 (滿分的 10%)**。
   輸出本身就只拿到保底以下的學生，分數由輸出決定，不會因為曾經 CE 反而比較高。

**編譯失敗不會是 0 分**：以下情況直接給保底分，備註寫明原因。
- 找不到 AI 工具、AI 超時、修了 2 次仍不能編譯、學生有多個 .c 檔。
- **AI 修改超過 30 個字**：可能順手修好了邏輯，不採用，報告標示「請老師確認」。

同一份原始碼的修正會存在 `測資資料夾\ai_fix_cache\`，重新批改時直接沿用，分數不會變，也不必再等 AI。
表格狀態顯示「CE→AI 修正」(淡藍底)；報告有「原始碼 vs 修正後」逐字對照；CSV 有 `FixChars`、`FixPenalty` 兩欄。
每位第一次 CE 的學生大約需要 30 秒到 2 分鐘。

`grader.cfg` 對應的設定：

```
ai_fix = 1                      # 0 = 不呼叫 AI，編譯失敗直接給保底分
ai_fix_tool = auto              # auto / claude / codex / gemini / 自訂命令列 (提示詞從 stdin 進、程式碼從 stdout 出)
ai_fix_penalty_per_char = 1
ai_fix_penalty_min_pct = 10     # 修正扣分下限 (滿分的 %)
ai_fix_penalty_max = 0          # 修正扣分上限 (0 = 不另設)
ai_fix_max_chars = 30           # AI 修改超過這麼多字就不採用 (0 = 不限)
ai_fix_cache = 1                # 同一份原始碼沿用上次的修正
ai_fix_attempts = 2
ai_fix_timeout_ms = 180000
ce_score_floor_pct = 10         # 編譯失敗保底分 (滿分的 %)
```

## 5. 公平性：工具自動處理 (報告與 CSV 備註會寫明)

| 情況 | 處理 |
|---|---|
| 原始碼存成 Big5 (或 Big5 與 UTF-8 混雜) | 逐行轉成 UTF-8 副本再編譯，不依賴 gcc 的字碼頁支援 |
| 資料夾有多個 .c 一起編譯失敗 | 改為只編譯 main.c (或第一個能編譯的) |
| .c 放在子資料夾 / 散裝 .c 檔 | 自動找到 (子資料夾最多 3 層) |
| 時間限制很短 (<10 秒) 時第一次超時 | 重跑一次確認才判 TLE |
| Windows 換行 `\r\n`、UTF-8 BOM | 一律視為相同 |
| 程式印完才當掉 | stdout 不暫存，印出的內容一定留得住，仍照常比對 |

仍會判錯 (學生程式問題)：編譯錯誤且 AI 修不好 (保底分)、當掉 (RE，預設仍比對當掉前的輸出)、無窮迴圈 (TLE，0 分)、無限輸出 (OLE，0 分)。

## 6. 命令列版

```
build\grader_cli.exe D:\hw\hw1.c --students D:\下載\作業1 [--template 2] [--csv result.csv] [--no-ai-fix] [--ai-tool codex]
build\grader_cli.exe D:\hw\hw1.c --tests-export 總表.txt      (匯出測資總表)
build\grader_cli.exe D:\hw\hw1.c --tests-import 總表.txt      (匯入，例如 AI 產生的)
powershell -ExecutionPolicy Bypass -File tools\ai_testcases.ps1 -Reference D:\hw\hw1.c -Count 8
```

## 7. 重新編譯

需要 MinGW-w64 (gcc、windres、mingw32-make)。gcc 在 PATH 就雙擊 `build.bat`；不在 PATH 時：

```
mingw32-make CC=C:\mingw64\bin\gcc.exe WINDRES=C:\mingw64\bin\windres.exe all test
```

`mingw32-make test` 會跑 855 項單元測試；`mingw32-make clean` 清掉 build\ 的產物。

## ⚠ 安全性

本工具會在你的電腦上**直接執行學生程式**。時間限制、輸出上限、記憶體上限、強制結束只能防止
寫錯的程式卡住批改，**無法防止惡意程式**。只用於批改自己課程的作業。
